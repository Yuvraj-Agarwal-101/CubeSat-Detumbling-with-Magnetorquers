\section{Reproducibility}
The shared source repository is available at
\href{https://github.com/Yuvraj-Agarwal-101/CubeSat-Detumbling-with-Magnetorquers}{the project repository}.
Publication of the Person 4 changes, evaluator access, the tested final commit,
and a clean clone reproduction of all engineering figures remain pending.
The final submission must replace this statement with the verified commit
identifier and reproduction evidence.

The reusable metrics are separate from study runners and plotting code.
Each case record contains configuration, initial state, ensemble seed,
time step, numerical evidence, runtime, outcome, and failure reason.
Successful histories are retained in compressed NumPy files. Figure
manifests associate figures with saved records, configuration hashes,
seed sets, and generator commands. The repository README gives exact
commands for tests and study execution. Synthetic demonstration outputs
carry explicit fixture labels and are not report results.
